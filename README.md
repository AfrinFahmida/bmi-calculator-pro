# BMI Calculator Pro

A modern and responsive BMI Calculator built with Flutter Web.

## Features

- Gender Selection
- Height Slider
- Weight Slider
- Age Selector
- BMI Calculation
- BMI Category Detection
- Ideal Weight Range
- Dynamic Health Tips
- Responsive Web Design
- Modern Dark UI

## Technologies Used

- Flutter
- Dart
- Material Design

## BMI Categories

- Underweight
- Normal
- Overweight
- Obese
